# Security and safety

VeloxScreen is early alpha and **can send real machine-control commands**. Use it only on a trusted local printer and network. Do not expose the Moonraker API or the touchscreen's X11 session publicly without an appropriate security architecture.

If you discover a security vulnerability, avoid posting exploit details or API tokens in a public bug report. Prefer GitHub's private vulnerability reporting feature if the repository owner has enabled it. For ordinary UI bugs, use the issue templates.

Always redact private addresses, tokens and printer configuration secrets when attaching logs.
